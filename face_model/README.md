# SignalWell — Facial Emotion Recognition (FER) Module

## Overview

The `face_model` module is the dedicated computer vision component of SignalWell. It detects human faces, extracts facial features and action units (AUs), mitigates environmental lighting distortions, and classifies 7 emotional states (`angry`, `disgust`, `fear`, `happy`, `neutral`, `sad`, `surprise`) using real-time edge inference.

```
       Live Camera / Image Stream
                  │
                  ▼
      [YuNet / MediaPipe BlazeFace]
         - 100+ FPS Face Detection
         - 5-Point Facial Landmark Localization
                  │
                  ▼
      [Affine Landmark Normalization]
         - Roll Angle Correction (Inter-ocular alignment)
         - Canonical 224x224 Facial Crop
                  │
                  ▼
      [Lighting & Contrast Invariance]
         - CLAHE (Tile Grid: 8x8, Clip Limit: 2.0)
         - Illumination balance across skin tones
                  │
                  ▼
      [MobileNetV4-FER / ResEmoteNet Backbone]
         - Squeeze-and-Excitation (SE) Channel Attention
         - High-salience AU feature extraction
                  │
                  ▼
      [Calibrated Temperature-Scaled Logits]
         - Neutral Logit Attenuation (Eliminates resting-face bias)
         - Disgust-Anger AU Disambiguation
                  │
                  ▼
      [Structured Emotion Vector & Wellbeing Indices]
         - P(Emotion) across 7 classes
         - Valence [-1.0, +1.0], Arousal [0.0, 1.0]
         - Fatigue & Stress Indicators
```

## Key Technical Specifications

| Parameter | Specification |
|---|---|
| **Input Resolution** | $224 \times 224 \times 3$ (RGB) |
| **Face Detector** | OpenCV YuNet DNN ($350$ KB) / MediaPipe BlazeFace ($400$ KB) |
| **Backbone Architecture** | MobileNetV4-FER / ResEmoteNet with Squeeze-and-Excitation (SE) |
| **Inference Latency** | $<12$ ms (CPU), $<3$ ms (GPU / WebGL) |
| **Memory Footprint** | $<18$ MB RAM |
| **Target Classes** | 7: `angry`, `disgust`, `fear`, `happy`, `neutral`, `sad`, `surprise` |
| **Supported Runtime Formats** | PyTorch (`.pt`), ONNX Runtime (`.onnx`), TensorFlow.js (`model.json`) |

## Calibrated Temperature-Scaled Logits

To solve the clinical and technical challenge where resting expressions are overwhelmingly misclassified as `neutral`, and subtle disgust is confused with anger, the inference engine applies calibrated logit scaling:

$$z'_{neutral} = z_{neutral} - \beta_{neutral}$$
$$z'_{disgust} = z_{disgust} + \gamma_{disgust} \cdot \mathbf{1}_{\{AU9 > \tau\}}$$
$$P(c) = \frac{\exp(z'_c / T)}{\sum_{j=1}^K \exp(z'_j / T)}$$

Where:
- $\beta_{neutral} = 0.55$: Neutral suppression penalty preventing majority class capture.
- $T = 0.85$: Temperature parameter sharpening confident facial activations.
- $AU9$: Wrinkled nose action unit detected via nasal-root landmark shortening.

## Quickstart: Python Standalone Inference

### 1. Install Dependencies
```bash
pip install -r face_model/requirements.txt
```

### 2. Test Live Webcam
```bash
python face_model/face_pipeline.py --source webcam --camera 0
```

### 3. Evaluate on Static Images
```bash
python face_model/test_face_model.py --image_dir SignalWell/app/test_photos/
```

## Clinical Safety & Ethical Disclaimer

> [!IMPORTANT]
> Facial expression classifications represent observable visual muscle movements (FACS Action Units) and **do not constitute definitive measurements of an individual's internal emotional state, mental health, or psychiatric diagnosis**. Environmental lighting, cultural display rules, neurodiversity, and physical fatigue heavily influence surface expressions. All metrics generated by this module are non-diagnostic and intended solely for research and supportive self-reflection.
